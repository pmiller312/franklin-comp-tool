✓ VACANCY VERIFICATION
All results are filtered to Ohio DTE vacant land class codes. Max Improvement Value sets the improvement value test applied to every parcel: = $0 is strictly vacant, a dollar amount allows a small tolerance, and Any applies no improvement test.
When a limit is set, all parcels in a multi-parcel sale (matched by date + price + owner) must pass — if any parcel exceeds the limit, the entire sale is excluded.
🛰 Imagery: The map opens on the dark basemap. The 🛰 button cycles to OSIP Ohio (6-inch, public domain, © OGRIP / Ohio DAS), then Esri World Imagery, then back to dark. OSIP is Ohio-specific leaf-off orthoimagery; resolution and vintage vary by county.

⚠ Razed-site detection is heuristic. Signals: keyword match in legal/deed (strongest, +3), utilities on vacant parcel (+1/+2), sale price 20×+ the auditor's appraised land value (+1/+2), platted lot number (+1). Score ≥ 2 = flagged. The value fields read here are appraised (market) values, not the 35% taxable figure. Across 2024–2026 vacant sales the median sale runs about 5× appraised land value and roughly a quarter exceed 20×, so treat the price signal as suggestive. Improvement figures come from the auditor's records, not a physical inspection, and a recent demolition or a lagging update can leave either field out of date. Verify individual comps independently.
